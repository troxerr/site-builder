# bartlettwebsitedesign.online

Homepage for Bartlett Website Design. A single static `index.html` with inline CSS and JS, plus the assets it references.

- `?preview` on the URL shows the dashed placeholder boxes (headshot, testimonials) that visitors don't see.
- Headshot: save a 400x500 portrait as `assets/austin.webp`, then swap the `.avatar` div in the About section for the `<img>` in the comment next to it.
- `demos/` (the 8 demo sites) is served from the live deployment and isn't in this repo yet, so deploy only `index.html` and `assets/` from here, or add `demos/` first.
